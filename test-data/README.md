# Scanly test fixtures

These files are generated for private testing and stay outside the APK.

- `scanner/synthetic/` contains 48 camera-style JPEGs across eight scanner conditions, with known page corners and a page-to-photo homography. The flat A4 pages in `_pages/` provide a rectification reference. They also provide paper and ink reference regions for measuring the effects of shadow correction.
- `scanner/desk/` contains 56 harder scenes in eight categories: single and clipped sheets on cluttered desks, white paper on light surfaces, open notebook spreads (both pages, or one page cut by the frame), fingers or pens over an edge, and dim lamp light. `tools/check.sh` requires at least 37 hits.
- `special/` contains 10 camera-style JPEGs of fake cards, curved book spreads, and framed whiteboards. Book truth includes the two projected gutter endpoints.
- `pdf/` contains 23 PDFs covering page edits, reader navigation, search, width normalization, encryption, sanitization, and batch handling. The batch includes a deliberately truncated file. The scan PDF uses five flat source pages downsampled to 760 × 1075 pixels with JPEG compression and has no text layer.

Each set has a `truth.json` file. The scanner and special sets also have a contact sheet with the truth quads drawn in green. Photo coordinates use pixel centers, and corner order follows the source page. PDF page references in truth are one-based, and PDF coordinates are in points from the bottom left.

Run from the repository root.

```powershell
& G:/Paperless-Scanner/.venv/Scripts/python.exe tools/fixtures/generate_all.py
& G:/Paperless-Scanner/.venv/Scripts/python.exe tools/fixtures/generate_all.py --only desk
```

All fixture content was generated by this repository. Windows fonts are used only to render pixels or PDF text. The rendered fixtures are intended for private testing. No font files are distributed here.

`imaging-goldens/` holds the Python reference outputs (detected quads, warps, filters, page tools) that the Kotlin instrumented tests compare against. Regenerate them with `tools/imaging-lab/make_goldens.py` after any algorithm change.
